# Crowd Alert Gym System

## Overview
A Python-based real-time gym crowd monitoring system that tracks occupancy using entry/exit logs from a CSV file.

## Features
- Real-time occupancy calculation
- Crowd level classification (Free, Busy, Crowded, Overcrowded)
- CSV data processing
- Alert logging system

## Tech Stack
- Python
- CSV File Handling
- Logic Building

## Purpose
This project simulates a smart gym monitoring system for crowd management using simple data analysis.
